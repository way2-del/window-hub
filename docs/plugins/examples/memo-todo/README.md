# 备忘 Todo（示例插件）

纯插件包：快捷区显示**当前任务**并打开弹窗；到点 `hub.notify`；岛下拉看详情。**不占用岛栏摘要**（`island.bar`）。数据键 `store`（`hub.storage`）。

## 安装

设置 → 插件市场 → **添加开发目录** → 选本目录（确认表面/能力后安装）。  
开发安装后 id 为 `com.example.memo-todo__dev`。  
若曾装过旧版，重装/重开后会 `clearBar` 清掉残留岛栏文案。

## 表面

| 表面 | 行为 |
|------|------|
| 快捷区 | **当前进行任务**摘要（标题/最近提醒）；点击开弹窗；前端轮询到点通知 |
| 弹窗 | 增删改、完成、设提醒（壳边距见 `window-hub-plugin-popup`） |
| 岛通知 | 到期横幅 + 完成/稍后按钮 |
| 岛下拉 | 待办详情（设置「下拉内容」选本插件） |
| 岛栏摘要 | **不写入**（仅 `clearBar` 清旧文案；`island.bar` 槽位只为门控清理） |

## 敏感能力

安装时会提示：`notify`（岛通知）。

## 通知按钮

到点横幅：`start`「完成」、`end`「稍后」。快捷区 `hub.notify.onAction` 处理。

## 已知局限

进程退出后前端定时器不跑。
