# 课表（course-schedule）

MA Design 学期课表插件。玻璃壳托管弹窗展示 **周视图整表**（周一至周日一列一张，可横/纵滑动），右上角 **UK / 中文** 切换文案与时区时间。

## 表面

| 表面 | 行为 |
|------|------|
| 快捷区 | 今日下一节摘要，点击打开弹窗 |
| 弹窗 | `#app.wg-shell` 玻璃壳；周表 + 图例；‹ › / 今天 导航时顶栏日期同步更新 |
| 岛面板 | 本周日程 **两列卡片**（可下滑；极窄侧栏自动单列） |

## 数据

日程内嵌于插件（与 `visualized_schedule` 一致），字段：`d` 日期、`t` 类型色、`en`/`cn` 标题、`l` 地点、`u` 英国时间、`c` 中国时间。

语言偏好存 `hub.storage` 键 `prefs`：`{ "tz": "CN" | "UK" }`。

## 安装

设置 → 插件 → **添加开发目录**，指向本目录（或 `docs/plugins/examples/course-schedule/`）。
