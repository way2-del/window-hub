# 歌词（官方插件）

监听网易云 **桌面歌词**，同步到灵动岛栏（类似 MyDockFinder）。

## 岛栏顺序

在 **设置 → 一般 → 岛栏顺序** 里用 ↑↓ 调整各 `island.bar` 插件的优先级。  
通知横幅固定最上；其下按你排的顺序竞选（例如歌词在天气上面）。

## 用法

1. 设置 → 插件 → 安装「歌词」并启用  
2. 设置 → 岛栏顺序 → 把「歌词」排到「天气」上方（按需）  
3. 网易云开启 **桌面歌词** 并播放  
4. 关闭桌面歌词后插件会清空岛栏，自动落到下一顺位（如天气）

## 技术

`hub.media.neteaseNowPlaying`（仅桌面歌词开启时写岛栏）：

1. 桌面歌词窗口 UIA / 子控件  
2. **SMTC 播放进度 + 网易云 LRC API**（适配 3.1.36 等自绘桌面歌词）  
3. 内存指针链 / 未知版本 RVA 自动探测  

快捷区入口为隐形 worker（宽 1px）。需能访问 `music.163.com`。
