# 歌词（官方插件）

监听网易云 **桌面歌词**，同步到灵动岛栏（类似 MyDockFinder）。

## 岛栏顺序

在 **设置 → 一般 → 岛栏顺序** 里用 ↑↓ 调整各 `island.bar` 插件的优先级。  
通知横幅固定最上；其下按你排的顺序竞选（例如歌词在天气上面）。

## 用法

1. 设置 → 插件 → 安装「歌词」并启用  
2. 设置 → 岛栏顺序 → 把「歌词」排到「天气」上方（按需）  
3. 网易云开启 **桌面歌词** 并播放  
4. **下拉灵动岛** 可上一首 / 下一首 / 播放暂停（系统多媒体键）  
5. 关闭桌面歌词后插件会清空岛栏，自动落到下一顺位（如天气）

## 技术

`hub.media.neteaseNowPlaying`（仅桌面歌词开启时写岛栏）：

1. 桌面歌词窗口标题 / 子控件文本（优先；暂停时随网易云停住）  
2. 官方 LRC + 本地播放时钟选句（读不到桌面字时的回退；面板点暂停会冻结时钟）  
3. HTTP 拉 LRC 仅在后台  

`hub.media.transport("prev"|"next"|"play-pause")`：发送系统多媒体键（不经 SMTC）。

快捷区入口为隐形 worker（宽 1px）。需能访问 `music.163.com`。
