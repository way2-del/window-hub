# 文件搜索（Everything）

官方插件：经 Host `hub.everything.*` 搜索本机文件。**仅灵动岛情景临时**，不进快捷区。

## 情景临时 / 仪表台页签

与「正在播放」同类有 **`island.scenario`** 槽，但 **Alt+空格不再激活独立搜索岛**。

| 操作 | 效果 |
|------|------|
| **Alt+空格** | 展开仪表台并切到「文件搜索」页签（壳 = 首页尺寸） |
| **岛栏导航第三钮** | 同上页签 |
| **再按 Alt+空格 / Esc** | 收起仪表台 |

空关键字 → 卡片组网格；有字 → Everything 结果。搜索在面板内完成，无岛栏独立搜索框。

设置 → 情景临时 列表仍可见本插件（门禁等配置保留）。

## 空态网格

- 外层 **2 列**；卡片占格 `w/h ∈ {1,2}`（默认新建整行 `2×1`，可放 8 个快捷）
- 组内快捷：列数随宽 `4×w`、行数随高 `2×h`；图标固定 28px 不随卡片拉伸
- 容量：`1×1→8`、`2×1→16`、`1×2→16`、`2×2→32`（多出的格子留空；多出的快捷仍保留在存储）
- 「历史搜索」为系统卡，可拖拽/改大小，不可删除

## 依赖

- 本机已安装并**正在运行** [Everything](https://www.voidtools.com/)
- Host 已内置 `Everything64.dll`

## 能力 / 槽位

| 项 | 用途 |
|----|------|
| `island.scenario` + `island.bar` + `island.panel` | 情景临时接管 |
| `everything.search` | 搜索 / 打开 / 定位 |
| `storage` | 分类文件夹、卡片组与历史（store v2） |
