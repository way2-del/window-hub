# 文件搜索（Everything）

官方插件：经 Host `hub.everything.*` 搜索本机文件。**仅灵动岛情景临时**，不进快捷区。

## 情景临时（可配置全局热键）

与「正在播放」同类：**`island.scenario`** 暂代岛栏 + 下拉，**不改**常驻/下拉 prefs。

快捷键在 **设置 → 快捷键** 与 **插件详情** 两处同源可改（`settings` 类型 `hotkey`）：

| 设置项 | 默认 | 效果 |
|--------|------|------|
| **打开搜索** | `Alt+Space`（与系统「打开搜索」同步） | claim 情景 → Everything 搜索面板 |
| **打开常用卡片组** | `Alt+Space+Space`（按住 Alt 连按两下空格） | 展开下拉并进入「常用」分类网格 |
| **回车 / 点「搜索」** | — | 空关键字 → 卡片组网格；有字 → Everything 结果 |
| **Esc / 再按打开搜索** | — | 退出搜索情景 |

设置 → 情景临时 列表可见本插件；可配存在门禁（默认无门禁即始终可 claim）。

## 空态网格

- 外层 **2 列**；卡片占格 `w/h ∈ {1,2}`（默认新建整行 `2×1`，可放 8 个快捷）
- 组内快捷：列数随宽 `4×w`、行数随高 `2×h`；图标固定 28px 不随卡片拉伸
- 容量：`1×1→8`、`2×1→16`、`1×2→16`、`2×2→32`（多出的格子留空；多出的快捷仍保留在存储）
- 「历史搜索」为系统卡，可拖拽/改大小，不可删除

## 依赖

- 本机已安装并**正在运行** [Everything](https://www.voidtools.com/)
- Host 已内置 `Everything64.dll`

## 能力 / 槽位

| 项 | 用途 |
|----|------|
| `island.scenario` + `island.bar` + `island.panel` | 情景临时接管 |
| `everything.search` | 搜索 / 打开 / 定位 |
| `storage` | 分类文件夹、卡片组与历史（store v2）；热键设置 |
