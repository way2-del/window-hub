# 背成语（官方示例）

随机成语背记插件：快捷区（左侧）显示当前词，点击在**芯片下方弹窗**揭晓释义 / 换一条。不展开中间灵动岛。

## API

`GET http://43.139.23.203:8765/api/random`

```json
{ "id": 283, "word": "扬汤止沸", "meaning": "比喻办法不彻底，不能从根本上解决问题。" }
```

需 `network` + `permissions.network`；经 `hub.fetch` 请求。

## 槽位

| 槽位 | 作用 |
|------|------|
| `shortcuts` | 左侧 chip 显示当前成语；`action: popup.open` |

## 设置

| Key | 说明 |
|-----|------|
| `autoRefreshSeconds` | 自动换词间隔（秒）；`0` = 仅手动 |
| `showMeaningAlways` | 为真时弹窗始终显示释义，隐藏「揭晓」；弹窗内也有开关，默认开启 |

## 安装

设置 → 插件 →「导入示例：背成语」，或添加本目录为开发目录。版本 ≥ 1.2.0 起改为弹窗，不再占用岛下拉；≥ 1.2.1 优化弹窗样式；≥ 1.2.3 弹窗内可开关「始终显示释义」，默认开启。
