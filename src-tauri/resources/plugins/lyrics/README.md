# 歌词（官方插件）

捕捉网易云 **桌面歌词窗**，缩小镜像到灵动岛栏（对齐 MyDockFinder「彩色映射」）。

## 岛栏顺序

默认竞选顺序：**歌词 > 待办 > 天气**（有内容才占位）。  
也可在 **设置 → 一般 → 岛栏顺序** 里用 ↑↓ 调整。  
通知横幅固定最上；其下按顺序竞选第一条有文案的插件。

## 用法

1. 设置 → 插件 → 安装「歌词」并启用  
2. 网易云开启 **桌面歌词** 并播放（建议 **横向单行**，窗不要太高）  
3. 岛栏直接显示桌面歌词的缩小截图（与桌面同步，无 OCR 错字/超前）  
4. **下拉灵动岛** 可上一首 / 下一首 / 播放暂停，以及 **打开网易云**  
5. 关闭桌面歌词后插件会清空岛栏，自动落到下一顺位（待办或天气）

## 技术

`hub.media.neteaseNowPlaying`：

1. 检测可见 `DesktopLyrics`  
2. 截取窗画面 → **裁切有字区域** → 黑底变透明 PNG（`lyricImage`）  
3. 插件 `hub.island.setBar({ image })` 贴到岛栏（约 2× 分辨率再 CSS 缩小）  

不做 OCR / 本地 LRC 选句。  

`hub.media.transport("prev"|"next"|"play-pause")`：系统多媒体键。  
`hub.media.openNetease()`：聚焦或启动网易云。

快捷区入口为隐形 worker（宽 1px）。
