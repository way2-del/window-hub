# 随心记（官方示例）

快捷区（左侧）chip；点击在**芯片下方**打开弹窗写随心记（`hub.popup.open`），不展开中间灵动岛。数据键 `store`（`hub.storage`）。

## 能力

- 多篇历史：右上角 **+** 新建；底部「历史」切换 / 删除
- 防抖自动保存（约 0.6s）；切换、关闭前也会落盘
- 空白篇会复用，避免堆一堆空篇；最多保留约 40 篇

## 槽位

| 槽位 | 作用 |
|------|------|
| `shortcuts` | 左侧 chip 显示当前随心记摘要；`action: popup.open` |

## 安装

首次启动若缺失会由 `ensure_official_plugins` 安装；也可设置 → 插件 →「导入示例：随心记」。版本 ≥ 1.1.0。
