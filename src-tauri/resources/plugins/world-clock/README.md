# 世界时钟

快捷区展示**另一时区**的时间（不与顶栏本机时钟重复）；点击打开双栏弹窗，可查看两个时区；弹窗右上角齿轮进入设置。

| 表面 | 行为 |
|------|------|
| 快捷区 | 标签 + 非本机时区的 `H:mm`；点击 → `hub.popup.open` |
| 弹窗 | 并排两列：时区名 / 大号时间 / 日期与上午下午 |
| 设置 | 弹窗内齿轮，或宿主插件设置页（`zoneA` / `zoneB`） |

默认：`zoneA = 本机时区`，`zoneB = Europe/London`。

## 显示设置

快捷区使用时钟图标代替城市名，悬停仍可查看城市。可选择日期、星期、时间的任意组合，或仅显示图标。日期与星期始终按快捷区所选时区计算。默认仅显示时间，使用 24 小时制；12 小时制会标记 AM/PM，弹窗标记上午/下午。弹窗齿轮和插件设置均可修改，保存后立即生效。
